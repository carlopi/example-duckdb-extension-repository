example-duckdb-extension-repository

This is a DuckDB extension repository: a static site that serves signed DuckDB extensions, laid out as <version>/<platform>/<name>.duckdb_extension.gz. It exists to demonstrate how a publisher hosts a repository on their own domain and how DuckDB finds and trusts it.

Use it

The host carlopi.github.io points DuckDB here from https://carlopi.github.io/.well-known/duckdb-extension-repo.json, so the repository is created by naming the host, with no url to type:

CREATE EXTENSION REPOSITORY carlopi.github.io;
INSTALL inet FROM carlopi.github.io;
LOAD inet FROM carlopi.github.io;

Or, naming this location directly:

CREATE EXTENSION REPOSITORY example WITH PREFIX 'https://carlopi.github.io/example-duckdb-extension-repository';

Signatures

Every extension here is signed with this repository's key. DuckDB pins the public key when the repository is created and verifies each extension against it at LOAD. The key is published in .well-known/duckdb-extension-repo.json, and CREATE EXTENSION REPOSITORY reports its fingerprint, which should read:

Contents

  • .well-known/duckdb-extension-repo.json: the repository's metadata, with its url and signing key.
  • v2.0.0/osx_arm64/inet.duckdb_extension.gz: the inet extension, DuckDB v2.0.0, macOS arm64, re-signed with this repository's key.
  • scripts/sign-extension.sh: signs an extension and places it in the layout above.
